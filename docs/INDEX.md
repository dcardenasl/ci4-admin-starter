# Documentation Hub: CI4 Admin Starter

Welcome to the official documentation for the **CI4 Admin Starter**. This hub is designed to help developers, DevOps engineers, and contributors understand, build, and maintain this frontend administrative template.

## 🧭 Navigation

### 🏗️ [Architecture & Core Concepts](./ARCHITECTURE.md)
Understand how the system works under the hood. Includes the request lifecycle, the `ApiClient` deep dive, and security patterns.

### 🎨 [Frontend & UI Guide](./FRONTEND.md)
Guidelines for building interfaces using Tailwind CSS, Alpine.js, and Lucide Icons. Learn about table management, modals, and built-in helpers.

### 🔌 [Services & Validation](./SERVICES.md)
How to communicate with the backend API. Covers the Service pattern, `BaseApiService`, and the `FormRequest` validation layer.

### 🧪 [Testing & Quality](./TESTING.md)
Our strategy for ensuring stability. How to write Unit and Feature tests, and how to mock the `ApiClient`.

### 🚀 [Deployment & DevOps](./DEPLOYMENT.md)
Everything you need to move from development to production. Environment variables, server configuration (Nginx/Apache), and security headers.

### 📚 [Guides & How-To](./HOW-TO.md)
Step-by-step instructions for common tasks like adding a new module or modifying the sidebar.
